# Include an account Storage Allowance

The GameWake MVP includes an account-wide Storage Allowance for Worlds and backups. Storage within the allowance does not consume Wallet credit while Worlds are asleep; only excess storage is billed per GB/month, with notice before the account crosses the limit. GameWake absorbs the common group's storage cost to preserve the simple promise that stopping play stops ordinary charges, while the allowance prevents unlimited free storage.
