# Use AbacatePay for MVP payments

GameWake uses AbacatePay API v2 as the MVP Payment Provider for one-time Wallet Contributions through Pix and card checkout. Fixed BRL credit packages map to active one-time AbacatePay products because v2 Checkout derives its amount from product IDs; GameWake verifies the returned and paid amount before crediting. Every webhook must pass both the URL secret and the documented Base64 HMAC-SHA256 signature over the raw body, and provider event IDs are processed once. Completed, refunded, and disputed payments create immutable Wallet Ledger entries; a provider reversal that cannot be fully compensated without a negative Wallet places funding in `Needs Review` instead. Only the payer sees checkout and payment-method details, product-initiated refunds are integral and require all contributed credit to remain available, and AbacatePay never becomes the Wallet source of truth. Threshold-triggered Auto Recharge remains outside the confirmed provider contract until AbacatePay documents a safe on-demand stored-payment capability.
