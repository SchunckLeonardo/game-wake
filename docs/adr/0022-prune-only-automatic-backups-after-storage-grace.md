# Prune only automatic Backups after storage grace

When a Wallet cannot fund excess storage, GameWake grants a thirty-day Storage Grace Period with repeated notices and blocks new Worlds and manual Backups. After grace it may prune only the oldest automatic Backups until usage falls, never the current World state or manual Backups; if excess remains, waking is blocked until an Owner contributes, exports, or removes data. This bounds ordinary unpaid retention without silently sacrificing irreplaceable customer data.
