# Keep World data portable

GameWake lets an Owner, or an explicitly authorized Custom Role, generate a free World Export at any time. The export contains native save files, effective configuration, relevant versions, and the backup manifest required to host the game outside GameWake, delivered through an expiring private link without changing the World. GameWake accepts the implementation and support cost of a portable format to avoid vendor lock-in and establish that the group's progress remains theirs.
