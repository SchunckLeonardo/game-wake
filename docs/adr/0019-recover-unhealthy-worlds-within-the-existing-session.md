# Recover unhealthy Worlds within the existing session

After a World reaches `Online`, GameWake automatically restarts an unhealthy game process and may replace a compromised Runtime from durable World state. Recovery remains inside the existing financial session and Session Quote, without a new Usage Reservation or duplicate charge, and is limited to three attempts within fifteen minutes before the World moves to `Precisa de atenção`. This favors hands-off play while bounding restart loops and preserving billing continuity.
