# Experience

Este contexto oferece uma experiência única e autorizada no Discord e na Web sem expor detalhes da nuvem.

## Surfaces and interaction

**World Onboarding**:
O fluxo guiado que cria um World dormindo e prepara seu primeiro despertar.
_Avoid_: cloud setup wizard, prepaid subscription, paid World creation

**Discord Integration**:
A conexão autorizada entre um GameWake Account e um Discord Guild.
_Avoid_: Discord Account, Discord-owned server

**GameWake Channel**:
O canal configurado para cards compartilhados e não sensíveis do grupo.
_Avoid_: access boundary, admin channel, secret store

**GameWake Console**:
A Web UI responsiva acessível em navegador e dentro do Discord como Activity.
_Avoid_: separate Discord UI, separate web control plane, bot-only administration

**Connection Details**:
O endereço, a porta e o eventual segredo necessários para entrar em um World.
_Avoid_: public online message, audit payload, permanent Discord post

**World Selection**:
A resolução do World permitido que será alvo de uma interação.
_Avoid_: server selection, account selection, unrestricted resource list

**Activity Event**:
Um registro imutável e redigido de uma ação relevante para o grupo.
_Avoid_: application log, mutable activity feed, secret-bearing audit record
